# Personal Portfolio Website

A modern, responsive, and interactive personal portfolio website developed by **Jeevitha S**, a Computer Science and Engineering student at Canara Engineering College. The website showcases my technical skills, academic background, projects, and professional interests through a clean and user-friendly interface.

## 👩‍💻 About the Project

This portfolio serves as a professional platform to present my technical knowledge, development skills, and project experience in areas such as **Java Development, Web Development, Artificial Intelligence, Machine Learning, and Data Analytics**.

Designed with a modern user interface, the website provides a seamless browsing experience across desktops, laptops, tablets, and mobile devices.

## ✨ Key Features

- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.
- **Professional Introduction:** Dedicated Home and About sections highlighting my background and interests.
- **Technical Skills:** Interactive skill sections with animated progress indicators.
- **Project Showcase:** Displays selected academic and personal projects with relevant details.
- **Interactive Navigation:** Responsive hamburger menu for mobile devices.
- **Dark and Light Mode:** Theme switching with preferences saved using LocalStorage.
- **Smooth Animations:** Scroll-based reveal effects and smooth navigation.
- **Reading Progress Indicator:** Visual indicator showing the page reading progress.
- **Technical Blog:** Dedicated blog page featuring technical articles.
- **Interactive Blog Articles:** Modal-based article previews.
- **Contact Form:** Client-side form validation for user input.
- **Social Media Integration:** Links to professional and social profiles.

## ⚙️ Installation and Setup

Follow these steps to run the project locally:

1. Clone the repository:

   ```bash
   git clone https://github.com/jjeevithas/Portfolio-Website.git
   ```

2. Navigate to the project directory:

   ```bash
   cd Portfolio-Website
   ```

3. Open the project in Visual Studio Code.

4. Install the **Live Server** extension if it is not already installed.

5. Open `index.html` in Visual Studio Code.

6. Right-click and select **Open with Live Server**.

7. Explore the portfolio and technical blog through the navigation menu.
