# Professional Portfolio Website

Frontend-focused college project using HTML5, CSS3 and JavaScript.

## Features
- Responsive design
- Animated scroll reveal
- Animated floating hero graphics
- Hamburger navigation on mobile
- Dark/light mode saved with localStorage
- Reading progress bar
- Skills progress bars
- Project image cards
- Separate technical Blog page
- Blog article modal interaction
- Contact form validation
- Resume download button
- Social links
- Responsive media queries

## Run in VS Code
1. Open this folder in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html` -> Open with Live Server.
4. Use the Blog link to open `blog.html`.

## Personalize
- Replace `your-email@example.com`.
- Replace LinkedIn and GitHub links.
- Replace `assets/Jeevitha_S_Resume.pdf` with your real resume PDF.
- Update education placeholders.
- Replace SVG project illustrations with your own screenshots if desired.

## Suggested submission explanation
This project demonstrates responsive UI design using HTML, CSS Flexbox/Grid and media queries. JavaScript is used for event handling, dark mode, mobile navigation, form validation, scroll animation, progress indicators and blog interactions.
