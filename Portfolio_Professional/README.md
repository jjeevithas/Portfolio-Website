# Jeevitha S — Personal Portfolio Website

A responsive and interactive personal portfolio website developed by **Jeevitha S**, a Computer Science Engineering student, to showcase technical skills, academic work, projects, education, and professional interests.

## 👩‍💻 About

This portfolio website presents my technical background, skills, projects, and learning journey in **Web Development, Java, Artificial Intelligence, Machine Learning, and Data Analytics**.

The website is designed with a clean, modern, and responsive interface for desktop, tablet, and mobile devices.

## 🚀 Features

* Responsive personal portfolio design
* Professional home and about sections
* Technical skills with animated progress bars
* Project showcase
* Responsive hamburger navigation
* Light and dark mode
* Smooth scroll and reveal animations
* Reading progress indicator
* Separate technical blog page
* Interactive blog articles
* Contact form validation
* Resume download option
* Social media links
* Responsive media queries

## 🛠️ Technologies Used

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project in **Visual Studio Code**.
3. Install the **Live Server** extension.
4. Open `index.html`.
5. Right-click and select **Open with Live Server**.
6. Explore the portfolio and blog pages.
